Ex. 1 React Lab Exercise: Understanding React File Structure 
Aim 
To create a basic React application using Vite and understand the purpose of important files and 
folders in the React project structure. 
Learning Outcomes 
After completing this exercise, students will be able to: 
• Create a React project using Vite. 
• Identify important React files and folders. 
• Understand the role of main.jsx, App.jsx, index.html, and package.json. 
• Create and use a simple React component. 
• Run and test a React application. 
 
Exercise: Create a Student Information App 
Step 1: Create a React Project 
Open VS Code → Terminal and execute: 
npm create vite@latest student-app 
Select: 
Framework: React 
Variant: JavaScript 
Then: 
cd student-app 
npm install 
npm run dev 
Open the URL displayed in the terminal, usually: 
http://localhost:5173/ 
 
Step 2: Understand the File Structure 
Your project will look approximately like this: 
student-app/ 
│ 
├── node_modules/ 
│ 
├── public/ 
│ 
├── src/ 

│   ├── assets/ 
│   ├── App.css 
│   ├── App.jsx 
│   ├── index.css 
│   └── main.jsx 
│ 
├── .gitignore 
├── index.html 
├── package.json 
├── package-lock.json 
└── vite.config.js 
Important Files 
File/Folder 
Purpose 
src/ 
Contains the main application source code 
App.jsx 
Main React component 
main.jsx 
Entry point of the React application 
App.css 
Styles for the App component 
index.css 
Global CSS styles 
public/ 
Static files 
index.html 
Main HTML page 
package.json 
Project information and dependencies 
node_modules/ 
Installed packages 
vite.config.js 
Vite configuration 
 
Step 3: Examine index.html 
Open: 
index.html 
Find: 
<div id="root"></div> 
Understand 
React uses this <div> as the root container where the React application is displayed. 
Conceptually: 
index.html 
     ↓ 
<div id="root"> 
     ↓ 
React Application 
 
Step 4: Examine main.jsx 
Open: 
src/main.jsx 

You will see code similar to: 
import { StrictMode } from 'react' 
import { createRoot } from 'react-dom/client' 
import './index.css' 
import App from './App.jsx' 
 
createRoot(document.getElementById('root')).render( 
  <StrictMode> 
    <App /> 
  </StrictMode>, 
) 
Important point 
This line connects React with the HTML: 
document.getElementById('root') 
And this renders the App component: 
<App />

Step 7: Import the Component 
Modify App.jsx: 
import Student from './components/Student' 
 
function App() { 
  return ( 
    <div> 
      <h1>Student Information System</h1> 
      <Student /> 
    </div> 
  ) 
} 
 
export default App 
Observe the relationship 
index.html 
    ↓ 
main.jsx 
    ↓ 
App.jsx 
    ↓ 
Student.jsx 
This is an important basic React file/component flow.

Key Concept to Remember 
React file flow: 
index.html 
     ↓ 
  main.jsx 
     ↓ 
   App.jsx 
     ↓ 
Components 
(Student / Course / Faculty) 
In React, you can use CSS in App.jsx in three simple ways. For beginners, start with CSS class + 
App.css. 
1. Using App.css — Recommended 
App.jsx 
import './App.css' 
 
function App() { 
  return ( 
    <div className="student"> 
      <h2>Student Details</h2> 
      <p>Name: Rahul</p> 
      <p>Register Number: 101</p> 
      <p>Department: CSE</p> 
    </div> 
  ) 
} 
 
export default App 
App.css 
.student { 
  background-color: lightgray; 
  padding: 20px; 
} 
 

.student h2 { 
  color: blue; 
} 
 
.student p { 
  color: green; 
} 
Here: 
App.jsx 
   ↓ 
className="student" 
   ↓ 
App.css 
   ↓ 
.student { ... } 
 
2. Inline CSS in App.jsx 
You can directly write CSS inside the element: 
function App() { 
  return ( 
    <div style={{ backgroundColor: "lightgray", padding: "20px" }}> 
      <h2 style={{ color: "blue" }}> 
        Student Details 
      </h2> 
 
      <p style={{ color: "green" }}> 
        Name: Rahul 
      </p> 
    </div> 
  ) 
} 
 
export default App 
Important: In JSX, CSS properties use camelCase. 
CSS                  JSX 
-------------------------------- 
background-color  →  backgroundColor 
font-size         →  fontSize 
text-align        →  textAlign 
 
3. Create a CSS object in App.jsx 
function App() { 
 
  const headingStyle = { 
    color: "blue", 
    backgroundColor: "lightyellow", 
    padding: "10px" 
  } 
 

  return ( 
    <div> 
      <h2 style={headingStyle}> 
        Student Details 
      </h2> 
    </div> 
  ) 
} 
 
export default App 
For your React lab 
I recommend teaching students in this order: 
External CSS → Inline CSS → CSS Modules 
For your current Student component, the simplest approach is: 
import './App.css' 
and then: 
.student h2 { 
  color: blue; 
} 
This keeps React code and CSS separate, which is easier to maintain.
